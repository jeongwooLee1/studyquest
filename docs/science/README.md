## 다시 풀기용 비슷한 문제 (SCI_TWINS)
- 과학은 숫자만 바꾸는 생성기(twins.ts)가 맞지 않아, 원래 문항마다 사람이 쓴 변형 문항을 둔다.
- 형식: `SCI_TWINS[원래 문항 id] = [{ text, options, answer, traps?, explain }, …]` — 문항마다 3개, 보기 5개, answer는 1부터.
- 문항 객체 안에 넣지 않은 까닭: `publicQ`는 answer·traps·explain만 빼므로 문항 안의 변형 문항 정답이 페이지로 나간다.
- 같은 개념·같은 함정을 다른 상황(다른 숫자·다른 생활 예)으로 묻는다.
- 보기 순서: 손으로 쓰면 정답이 2·3번에 몰려서 `mixOptions`로 문항 id에 따라 정해진 순서로 섞는다. 숫자 보기·ㄱㄴㄷ 묶음 보기·순서 있는 보기는 그대로 두고 변형 문항에 `keepOrder: true`를 붙인다(twinOf가 다시 섞지 않게). 이미 배포된 기체 문제지 본문은 응시 기록과 맞추려고 섞지 않았다.

## 검증
- 구조: 모든 문항·변형 문항의 answer 범위, traps가 정답이 아님, 보기 중복 없음, 영역 연결, 변형 2개 이상 — 스크립트로 확인(오류 0).
- 내용: 무게 = 9.8 × 질량, 달의 중력 = 지구의 약 1/6, 용수철 비례·전체 길이, 부력 = 공기 중 무게 − 물속 무게 계산값과 섞은 뒤 정답 보기 문구를 하나씩 직접 확인.
- 내용(기체): 보일(압력 × 부피 일정)·샤를(0 °C 273 mL, 1 °C당 1 mL — 0 °C 부피의 1/273) 계산값과 생활 예 분류를 직접 확인.

## 결정과 이유
- 강의 번호·제목은 EBS 개념책(2022개정) 강의 목록 기준. 43·44강 제목은 미확인.
- 진단(sci-gas-diag)은 정답 비공개(practice:false), 다시 풀기는 n50·n54로.
- 배포된 문제지 본문의 보기 순서는 바꾸지 않는다: 응시 기록이 답 번호로 저장돼 있어 어긋난다. 아직 안 푼 문제지만 `mix` 값으로 조정.
- 정답 번호 기준: 8문항 문제지는 한 번호 최대 3개·4개 이상 번호 사용, 20문항은 번호마다 4개.
- 태양계(60~72강)는 진단 결과를 본 뒤 만든다(T-4). 학교 기말 범위·출판사는 미확인(학교 사이트가 이 환경에서 차단).

## 찍기 경고 기준 (fastSec, T-17)
- 규칙 하나·짧은 문장·짧은 보기로 바로 풀리는 문항에만 `fastSec: 2`(2초 미만일 때만 경고). 나머지는 기본 5초.
- 붙인 원래 문항 16개: 단위·화살표 뜻(f37-2·f37-3), 힘의 정의(f38-1·f39-1·f40-1·f41-1·sgd-1), 방향 하나(f39-2·f40-2·f41-2·sgu-3), 멈추게 한 힘(f40-8), 온도↑↓→부피(sgd-7·sc-1), 압력 n배→부피 1/n(sb-1·sgu-9).
- 변형 문항은 같은 기준으로 하나씩 골랐다(26개). "아닌 것" 고르기, 생활 예 적용, 계산, 정지 마찰처럼 함정이 있는 변형은 뺐다.
- 붙이지 않은 것: 계산·표 읽기·ㄱㄴㄷ 묶음·생활 예 분류·"않은/다른" 고르기·긴 지문(40자 넘는 상황 설명).
