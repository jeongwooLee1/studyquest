# 국어 결정과 이유

| 결정 | 이유 |
|---|---|
| 출판사와 관계없이 2022 개정 성취기준으로 문제지를 만든다 | 도농중 국어 출판사를 웹에서 못 찾음(학교 사이트·학교알리미 접속 불가). 첫 진단 때 교과서 표지를 받기로 함 |
| 전부 객관식(5지선다), 서술형은 「알맞은 문장 고르기」로 바꾼다 | 사이트 채점 형식이 choice·num뿐 |
| 지문은 직접 쓴다. 교과서 작품 전문은 넣지 않는다 | 저작권 |
| 진단은 practice:false, 단원·10분 문제지는 practice:true | 진단은 재응시 대비로 정답 비공개 |
| 다시풀기 변형은 문항당 3개, 함정 노트는 원래 문구와 같게 | HQ 공통 형식(VARIANTS[원래 id]) |
| 순서 있는 보기(1개~5개, 문장 종류 등)는 keepOrder:true | 섞으면 읽기 어려움 |
| 변형 정답 자리가 한쪽에 몰리면 rot()로 보기를 돌린다 | 같은 번호만 찍어 맞히지 않게 |
| 다희 문제지는 질문 조건(아닌 것·남은·두 번째·모두)에 함정을 둔다 | 끝까지 안 읽는 습관 |
| 시간: 다연 화·목 20분 + 월수금 10분(kor-m1-v5), 다혜 매일 20분, 다희 15분+독서 15분 | HQ 확정 |
| 지문 없이 낱말·사실 하나로 바로 고르는 문항(어종·관용구·속담·사자성어·맞춤법 한 낱말 등)은 fastSec: 2 | 규칙으로 2초에 풀어도 찍기 경고가 떠서(T-16). 지문·문장 분석·비교 문항은 5초 그대로. 변형은 문항마다 따로 판단 |
| 원래 문항이 2초인데 2초가 아닌 변형은 fastSec: 5를 적는다 | twinOf가 변형에 값이 없으면 원래 문항 값을 물려줌(T-18) |
