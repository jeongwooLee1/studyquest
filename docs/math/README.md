# 수학 문제지 — 결정과 이유

## 문제 만드는 방식
- 모든 문항은 twins.ts 생성기 `G['<id>'] = (r) => build(r, Spec)`를 정해진 seed로 돌려 만든다(`makeFixed(id, area, seed)`). 같은 생성기로 틀린 문제 다시 풀기도 만든다 → 문항 id마다 생성기 필수.
- 함정 보기는 실제 실수(노트에 이유)를 계산해서 넣고, 남는 칸은 `fill`로 채운다. 같은 값 보기·정답에 함정 금지.
- 보기 순서: 수는 `asc`. 이름·구간처럼 순서가 있는 글 보기는 `order:'fixed'`로 만든 뒤 다시 정렬(timeOrder, nameOrder).
- seed 고르기: 한 문제지 안에서 정답 위치 1~5가 고르게, 소재(주제)가 겹치지 않게.

## 검증 (커밋 전 필수)
- 생성기마다 seed 3000개로 문제 글·그림 좌표에서 값을 따로 다시 읽어 정답을 재계산(생성기 코드 재사용 금지).
- 보기 개수·중복, NaN, 정답에 함정, 정답 위치 분포 확인. 그림은 lt-common.js로 그려 스크린샷 확인.
