# 도형 그림 형식 (문항의 `fig`)

문항 객체의 `fig` 필드로 그림을 넣는다. 지금 `LT.figure` 는 `type: 'coord'`(좌표평면)만 그린다.
여기에 `type: 'shape'`(평면도형)과 `type: 'solid'`(입체도형) 두 가지를 더한다.

- 모르는 `type` 은 그리지 않는다(지금과 같음). 그래서 **문항 글만으로 풀 수 있게** 쓰고, 그림은 돕는 용도로만 쓴다.
- 그림 길이는 실제 비율에 맞추지 않아도 된다(문항 글의 숫자가 기준).
- 틀린 문제 다시 풀기(twins.ts)도 같은 형식의 `fig` 를 만든다. 서버는 `fig` 를 그대로 저장·전달만 한다(index.ts 수정 없음).
- 크기: 지금 `.fig svg { max-width: 220px~260px }` 그대로. 선 굵기·글자 크기는 viewBox 크기와 상관없이 같게(아래 "그리기 규칙").

---

## 1. `type: 'shape'` — 평면도형

```js
fig: {
  type: 'shape',
  pts: { A: [0, 0], B: [8, 0], C: [10, 5], D: [2, 5], _h: [2, 0] },
  items: [
    { k: 'poly', p: ['A', 'B', 'C', 'D'] },
    { k: 'seg', p: ['D', '_h'], dash: true, label: '5 cm' },
    { k: 'right', p: ['D', '_h', 'B'] },
    { k: 'side', p: ['A', 'B'], label: '8 cm' },
  ],
}
```

### pts — 점
- `이름: [x, y]`. **y는 위쪽이 +** (수학 좌표). 그릴 때 뒤집는다.
- 이름이 `_` 로 시작하면 이름표를 쓰지 않는다(보조점).
- 이름표는 점에서 도형 중심(모든 점의 평균) 반대쪽으로 조금 떨어뜨려 쓴다. 한글 이름(ㄱ, ㄴ …)도 그대로.
- 보이는 범위: 모든 점 + 원(중심±반지름)을 감싸는 상자 + 여백(이름표·길이 글자가 들어갈 만큼, 짧은 변의 15% 정도). 가로·세로 비율은 유지.

### items — 그릴 것 (적힌 순서대로 그림. 뒤에 있는 것이 위)

| k | 필드 | 그림 |
|---|---|---|
| `poly` | `p: [점…]`, `fill?: true \| 'bg'`, `dash?` | 닫힌 다각형. `fill: true` 연한 색 칠, `'bg'` 는 배경색으로 칠해 아래 그림을 지움(구멍) |
| `seg` | `p: [P, Q]`, `dash?`, `label?` | 선분. `label` 은 선분 가운데에 붙임(선분 바깥쪽 = 중심 반대쪽) |
| `side` | `p: [P, Q]`, `label` | 선은 그리지 않고 길이 글자만 붙임(이미 `poly` 로 그린 변의 길이) |
| `line` | `p: [P, Q]` | 두 점을 지나는 직선(보이는 범위 끝까지) |
| `ray` | `p: [P, Q]` | P에서 시작해 Q 쪽으로 끝까지 |
| `angle` | `p: [A, O, B]`, `label?`, `n?: 1\|2` | 꼭짓점 O, 반직선 OA→OB **반시계 방향**으로 호. `n` 은 호 개수(같은 각 표시). `label` 은 호 바깥 가운데 |
| `right` | `p: [A, O, B]` | O에 직각 표시(작은 사각형) |
| `tick` | `p: [P, Q]`, `n?: 1\|2\|3` | 같은 길이 표시(선분 가운데 짧은 빗금) |
| `par` | `p: [P, Q]`, `n?: 1\|2` | 평행 표시(선분 가운데 작은 화살촉) |
| `circle` | `c: 점`, `r: 수`, `fill?`, `dash?` | 원 |
| `arc` | `c: 점`, `r`, `from`, `to`, `sector?: true`, `fill?`, `label?` | 호. 각도는 도(°), x축 + 방향에서 반시계. `sector` 면 중심과 이어 부채꼴, `label` 은 호 바깥 가운데 |
| `dot` | `p: 점` | 점 찍기(원의 중심 등) |
| `text` | `at: 점 \| [x, y]`, `s: 글` | 글 쓰기(가운데 맞춤) |

### 예시
- 평행사변형(밑변·높이): 위 예시.
- 삼각형 높이가 바깥에 있을 때: `seg` 를 밑변 연장선으로 `dash: true`, 높이도 `dash`.
- 마름모와 두 대각선: `poly` + `seg` 2개(`label` 은 대각선 길이) + 중심 `right`.
- 정사각형 안의 원, 원 밖 부분 색칠:
  `[{ k:'poly', p:[A,B,C,D], fill:true }, { k:'circle', c:'O', r:3, fill:'bg' }, { k:'circle', c:'O', r:3 }]`
- 평행선과 동위각·엇각: `line` 2개 + `par` + `line` 1개(가로지르는 직선) + `angle`.
- 작도: `circle`/`arc`(`dash: true`) + `ray`.

## 2. `type: 'solid'` — 입체도형

겨냥도(빗각 투영: 안쪽 깊이는 오른쪽 위 30°, 길이 0.5배)로 그린다. **보이지 않는 모서리는 점선.**

```js
fig: { type: 'solid', kind: 'cuboid', a: 8, b: 5, c: 3, labels: { a: '8 cm', b: '5 cm', c: '3 cm' } }
```

| kind | 필드 | 모양 |
|---|---|---|
| `cuboid` | `a` 가로, `b` 깊이, `c` 높이 | 직육면체(정육면체는 a=b=c) |
| `prism` | `n` 밑면 변 수(3~8), `r` 밑면 외접원 반지름, `h` 높이 | 정n각기둥 |
| `pyramid` | `n`, `r`, `h` | 정n각뿔 |
| `frustum` | `n`, `r`, `r2` 윗면, `h` | 각뿔대 |
| `cylinder` | `r`, `h` | 원기둥(밑면은 타원, 뒤쪽 반은 점선) |
| `cone` | `r`, `h` | 원뿔(꼭짓점–밑면 가운데 높이 점선은 `show: ['h']` 일 때만) |
| `sphere` | `r` | 구(가운데 타원 적도, 뒤쪽 반 점선) |
| `hemisphere` | `r` | 반구 |

- `labels`: 어떤 길이에 글자를 붙일지. 키는 `a, b, c, r, h, r2, l`(원뿔 모선). 값이 있는 것만 붙인다. `r` 은 밑면 중심에서 반지름 선분을 그려 붙임.
- `show?: ['h', 'r', 'axis']` — 높이 점선, 반지름 선, 회전축(일점쇄선)을 그림.

### 회전체·전개도
- 회전체 문제는 **회전하기 전 평면도형 + 축**을 `type: 'shape'` 로 그린다(`line` 에 `dash: true` 로 축). 돌린 결과 그림은 보기·풀이에서 말로 설명.
- 전개도는 `type: 'shape'` 로 그린다(원기둥 전개도 = `poly` 직사각형 + 위아래 `circle`).

## 3. 그리기 규칙
- viewBox 는 위 "보이는 범위"에서 계산, 선 굵기·글자 크기는 `vector-effect: non-scaling-stroke` 또는 범위 크기에 비례해 바꿔서 화면에서 항상 같게(선 1.6px, 글자 13px 정도).
- 색: 선 `currentColor`, 칠 `fill: true` 는 강조색 15% 투명도, `'bg'` 는 카드 배경색. 다크 모드에서도 보이게 CSS 변수 사용.
- `label` 글자에 `$…$`, `[[a|b]]`(분수)가 오면 `LT.md` 와 같은 방식으로 바꿔 쓴다(SVG 안에서는 `a/b` 로 써도 됨).
- 접근성: `<svg role="img" aria-label="도형 그림">`.

## 4. 이 형식을 쓰는 문제지
- `g-area`(평면도형의 넓이), `g-circle`(원의 둘레와 넓이) — 이번 브랜치. `shape` 만 사용.
- `g-solid`(입체도형) — `solid`(cuboid·prism·pyramid) + `shape`(전개도, 돌리기 전 도형과 축).
