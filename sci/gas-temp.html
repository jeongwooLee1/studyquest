기체의 온도와 부피, 어떤 관계일까? (샤를 법칙)

중1 과학 · 탐구 실험 2개를 그림으로 한 단계씩 따라가 봐요.

실험 1. 스포이트로 온도와 부피 관계 알기

1스포이트 끝을 자른다

스포이트의 뾰족한 끝을 2 cm 정도 가위로 잘라 내요.

그러면 둥근 주머니 + 가는 관 모양이 되고, 관 끝에 입구가 뚫려요. 잘린 조각은 쓰지 않아요.

2스포이트를 자에 붙인다

스포이트를 자에 셀로판테이프로 붙여요.

이때 둥근 부분의 맨 끝을 자의 0 cm에 맞춰요. 관 쪽으로 갈수록 눈금이 커져요.

3색소 탄 물 1방울 넣기

다른 스포이트로 빨간 식용 색소를 탄 물을 관의 입구에 1방울 넣어요.

물방울이 관 안에 마개처럼 끼어서 둥근 부분 쪽 공기를 가둬요. 물방울의 위치는 0 cm에서 물방울까지의 거리로 읽어요.

4온도가 다른 물에 차례로 담그기

온도가 다른 물 4비커(15.7, 22.6, 29.2, 40.6 °C)를 준비해요. 자에 붙인 스포이트를 세워서 둥근 부분(갇힌 공기)이 물에 잠기게 하고, 차가운 비커부터 차례로 넣어요. 온도계도 함께 꽂아 온도를 재요.

갇힌 공기가 데워져 부피 ↑ → 물방울을 위로 밀어 올려요 (노란 화살표)

점선 동그라미는 앞 비커에서의 물방울 위치예요. 물이 따뜻해질수록 물방울이 입구 쪽으로 올라가요.

5결과 표와 그래프

물의 온도 (°C)15.722.629.240.6
물방울 위치 (cm)9.510.010.711.4

온도가 높아질수록 물방울 위치도 거의 직선으로 올라가요. 온도가 오르면 부피가 커진다는 뜻이에요.

핵심 정리
  • 물방울은 움직이는 마개예요. 바깥 공기가 누르는 압력은 그대로(일정)예요.
  • 바뀐 것은 갇힌 공기의 온도뿐이에요.
  • 물방울이 밀려난 만큼이 늘어난 부피예요.
  • 갇힌 공기의 입자 수는 그대로예요.

실험 2. 온도와 부피, 입자 모형 그려 보기

주사기에 공기를 가둬요

주사기 입구를 마개로 막아 공기를 가둬요. 피스톤은 손으로 잡지 않고 자유롭게 움직이게 둬요. 그러면 바깥 공기가 누르는 압력(노란 화살표)이 늘 같아요. 온도만 바꿀 때 입자가 어떻게 되는지 그려 봐요.

세 그림 모두 입자는 8개로 같아요. 달라지는 건 입자의 빠르기와 입자 사이 거리예요.

왜 이렇게 될까?

❄ 차갑게 하면

입자가 느리게 움직여요 → 벽(피스톤)을 약하게 쳐요 → 바깥 공기가 피스톤을 밀어 넣어요 → 부피 감소

🔥 뜨겁게 하면

입자가 빠르게 움직여요 → 벽(피스톤)을 세게 쳐요 → 피스톤이 밀려 나가요 → 부피 증가

변하지 않는 것

  • 입자 수
  • 입자 크기
  • 입자 질량
  • 압력 (바깥과 같음)

변하는 것

  • 입자 운동 속도
  • 충돌 세기
  • 입자 사이 거리
  • 부피

실험 1과 이어서 보기

실험 1의 물방울이 실험 2의 피스톤과 같은 일을 해요. 둘 다 바깥 압력을 받으며 움직이는 마개라서, 기체의 부피가 늘면 밀려 나가요.

정리

샤를 법칙

압력이 일정할 때, 기체의 온도가 높아지면 부피가 커지고(온도 ↑ → 부피 ↑), 온도가 낮아지면 부피가 작아져요(온도 ↓ → 부피 ↓).
